Music-controlled light effect for the FMDX web server

## Version 1.0

- Music-controlled light effect with configuration interface

## Installation notes:

1. [Download](https://github.com/Highpoint2000/LightFX/releases) the last repository as a zip
2. Unpack all files from the plugins folder to ..fm-dx-webserver-main\plugins\ 
3. Stop or close the fm-dx-webserver
4. Start/Restart the fm-dx-webserver with "npm run webserver" on node.js console, check the console informations
5. Activate the LightFX plugin in the settings
6. Stop or close the fm-dx-webserver
7. Start/Restart the fm-dx-webserver with "npm run webserver", check the console informations on node.js console

## Configuration options:

Pressing and holding the LightFX button opens the settings window. There, the lighting effect can be configured individually. The settings are then restored when the web server loads in the browser.
